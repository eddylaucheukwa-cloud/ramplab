# Changelog

## 1.0.1 — First public release

- Added the GitHub README, illustrated Blender tutorial, and portable example project.
- Dominant Palette and Tonal Shading extraction with editable native previews.
- Rectangle/polygon regions, enabled-region unions, and separate region ramp generation.
- Create/update ColorRamp operations with undo support.
- Fixed normal image path conversion during save so it does not invalidate regions.
- Tested in Blender 5.1.0; 4.5/5.2 runtime verification remains pending.
